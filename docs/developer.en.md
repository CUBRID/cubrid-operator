# Developer Guide

## Overview

The environment setup and tool usage for developing the cubrid-operator project is explained.

## 1. Development Tool Installation

### Prerequisites

- Go 1.23.0+
- Docker 26.1.4+
- kubectl 1.30.1+
- Helm 3.0+

### Go Installation
cubrid-operator requires Go 1.23.0 or higher.

```bash
# Linux/macOS
wget https://go.dev/dl/go1.23.11.linux-amd64.tar.gz
sudo tar -C /usr/local -xzf go1.23.11.linux-amd64.tar.gz
export PATH=$PATH:/usr/local/go/bin
```

### kubectl Installation
kubectl 1.30.1 is required to interact with Kubernetes clusters.

```bash
# Linux (CentOS/Rocky Linux)
curl -LO "https://dl.k8s.io/release/v1.30.1/bin/linux/amd64/kubectl"
chmod +x kubectl
sudo mv kubectl /usr/local/bin/
```

### Helm Installation
Helm, the Kubernetes package manager, is required.

```bash
# Linux/macOS
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash
```

### Docker Installation (Optional)
Docker is required to build container images locally.

```bash
# CentOS/Rocky Linux
sudo yum install -y yum-utils
sudo yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
sudo yum install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl start docker
sudo systemctl enable docker
sudo usermod -aG docker $USER
```

## 2. Development Environment Setup

### Clone Project
```bash
git clone https://github.com/CUBRID/cubrid-operator.git
cd cubrid-operator
```

### Install Dependencies (Optional)
```bash
go mod download
```

### Install Go Tools
Install the Go tools used in the project.

```bash
# Install Go tools in the project's bin directory
make install-tools
```

**Installed Go tools:**
- kustomize (v5.3.0) - Kubernetes manifest management
- controller-gen (v0.14.0) - Kubernetes controller code generation
- envtest (release-0.17) - Test environment setup
- golangci-lint (v1.54.2) - Go code linter
- gofumpt (v0.8.0) - Go code formatter

### kubectl Cluster Admin Permission Setup
Setup for accessing Kubernetes cluster with cluster admin permissions.

```bash
# 1. Create kubeconfig directory
mkdir -p $HOME/.kube

# 2. Copy admin certificate (run on API server node)
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config

# 3. Change ownership (enable kubectl use with regular user permissions)
sudo chown $(id -u):$(id -g) $HOME/.kube/config

# 4. Test connection
kubectl cluster-info
kubectl get nodes

# 5. Verify permissions
kubectl auth can-i --list
```

### Environment Variable Setup (Optional)
```bash
# Go module settings (default works well, set only if needed)
# export GO111MODULE=on
# export GOPROXY=direct

# kubectl context setup (if needed)
kubectl config use-context <your-cluster-context>
```

## 3. Makefile Command Guide

You can perform various development tasks through the project's Makefile. For detailed information, refer to the `Makefile` in the project root.

### Basic Commands

#### Build
```bash
# Build entire project
make build
```

#### Code Quality Check
```bash
# Run golangci-lint
make lint

# Code formatting
make fmt
```

#### Cleanup
```bash
# Clean build artifacts and cache
make clean
```

### Go Tools Management

#### Install Go Tools
```bash
# Install all Go tools needed for development
make install-tools
```

#### Check Go Tools Version
```bash
# Check versions of installed Go tools
make version
```

### Container Related

#### Build Docker Image
```bash
# Build Docker image locally
make docker-build

# Build with specific version tag
make docker-build cubrid/cubrid-operator:latest

# Or use IMG variable
make docker-build IMG=cubrid/cubrid-operator:1.0.0
```

**Docker image tag format:**
```
[registry/]image-name:tag
```

### Deployment Related

#### Generate Manifests and CRDs
```bash
# Generate RBAC, Webhook, CRDs configuration
make manifests
```

#### Install/Uninstall
```bash
# Install using YAML file generated by build-installer
make build-installer
kubectl apply -f deploy/manifests/cubrid-operator.yaml

# Uninstall using YAML file generated by build-installer
kubectl delete -f deploy/manifests/cubrid-operator.yaml

# Install Helm chart
make helm-install

# Uninstall Helm chart
make helm-uninstall
```
