# Installation Guide

## Overview

There are two ways to install cubrid-operator:

## Installation Methods

### 1. Installation using Helm
To install cubrid-operator using Helm charts, refer to the [Helm Chart Documentation](./helm-chart.en.md).

### 2. Installation using Manifests
To install cubrid-operator by directly applying Kubernetes manifest files, refer to the [Manifest Installation Documentation](./manifest-installation.en.md).

## Recommendations

- **Development/Test Environment**: Manifest installation method is recommended.
- **Production Environment**: Helm chart installation method is recommended.

## Prerequisites

- Kubernetes cluster (v1.19 or higher)
- kubectl must be installed
- Helm installation (when using Helm charts)

For detailed installation methods and configuration options, refer to each guide document above.
